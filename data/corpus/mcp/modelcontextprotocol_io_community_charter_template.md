## Submitting a charter
- The group must already be sponsored under Forming a group .
- Copy the template below into the charter file and replace the placeholders. Delete the {/* */} guidance comments or leave them as written: HTML comments break the MDX build, and npm run format corrupts a {/* */} comment that spans lines.
- Run npm run prep , then push.
- Open a pull request that adds the charter file, a navigation entry under Working Groups or Interest Groups in docs/docs.json , and a line under Current groups .
- A Core Maintainer will review the pull request, as outlined in the Amending or retiring a group requirements.
- Later changes follow Amending or retiring a group and add a row to the charter’s Changelog.
