Check the roadmap
Bring it to a working group
Draft a SEP the group sponsors
Bring it to the Core Maintainers

## Other ways to help
- Review open SEPs and draft specification pull requests.
- Reproduce reported bugs.
- Test SDK release candidates against the draft specification.
- Write conformance scenarios. A Standards Track SEP with observable protocol behavior needs one to reach Final.

## Ground rules
- The Code of Conduct applies in every repository, channel and meeting.
- Disclose any AI assistance in the pull request or issue.
- AI agents must follow AGENTS.md , which limits when they can open issues and pull requests.
- Contributions are licensed under Apache-2.0 for code and specifications and CC-BY-4.0 for other documentation.
