## Channels
Discord
Real-time coordination among contributors, including working group, interest group and SDK discussion
Meeting calendar
Open group and maintainer meetings. For how meetings run, see Meetings and channels
GitHub Discussions
Ideas, feature requests with rationale, questions, roadmap discussion, announcements and releases, and meeting agendas and notes (Meeting Notes category)
GitHub Issues
Reproducible bugs, scoped documentation tasks, and CI and release tasks, filed through the issue forms. SEPs are pull requests to seps/ , not issues
Security advisories
Vulnerabilities. Never post one in a public channel
